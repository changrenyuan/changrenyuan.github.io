Hexo博客集成AI驱动的高清Live2D

changrenyuan
2025-12-19
-web -UI -AI Created

1. 项目背景

传统的 Live2D 插件（如 live2d-widget）存在以下痛点：

  • 资源依赖不稳定：官方 CDN 经常连接失败导致模型无法加载。

  • 画面模糊：在高分屏（Retina）上存在明显的锯齿和模糊。

  • 交互死板：只能循环播放预设语录，缺乏智能化交互。

2. 核心解决方案

A. 渲染引擎升级（PixiJS）

摒弃了旧版的 DOM 操作，改用 PixiJS v5 配合 pixi-live2d-display 插件进行 Canvas 渲染。

  • 高清适配：通过 window.devicePixelRatio 获取屏幕物理像素比，开启 autoDensity 确保模型在 Retina 屏幕上依然锐利。

  • 本地化部署：将依赖项（PixiJS、Cubism Core、Adapter）全部放在博客 /js/pixi/ 目录下，彻底解决网络报错 Event {isTrusted: true, type: 'error'}。

B. Cloudflare Workers AI 后端集成

利用 Cloudflare 原生生态构建了一个轻量级 AI 中转站：

  • Serverless 架构：基于 Hono 框架，在 Cloudflare Workers 上部署 api/ai/z16-chat 接口。

  • Llama-3.1 驱动：使用 env.AI.run 直接调用 @cf/meta/llama-3.1-8b-instruct 模型。

  • 上下文感知：后端通过请求头获取用户的地理位置，通过 Query 参数获取当前文章标题，动态生成 Prompt。

C. 自动化轮询与 UI 交互

  • 10s 轮询机制：前端 setInterval 每 10 秒请求一次 AI 接口，并检查对话框状态，实现看板娘的“自发性”发言。

  • 动态 UI 注入：完全移除 HTML 预留标签，改用 JS 动态注入容器、Canvas 和对话气泡，实现零侵入式集成。

  • 动作联动：通过监听模型 hit 事件（触摸头、身体）触发特定 motion，并联动 AI 文本显示。

4. 遇到的问题与避坑指南

1. 跨域与权限问题 (CORS)

由于后端 Worker 与博客可能不在同一域名，必须在 Hono 中开启 cors() 中件间，允许前端跨域访问。

2. Git 提交时的权限报错

  • 现象：文件所有者显示为 BUILTIN/Administrators。

  • 原因：由于使用管理员权限运行终端或 Git 安全策略更新。

  • 对策：使用 git config --global --add safe.directory "*" 标记目录安全，或使用 takeown 修复文件所有权。

3. 模型对齐

使用 model.anchor.set(0.5, 1) 将锚点设在脚底，配合 model.y = app.screen.height，确保角色在各种分辨率下都能“站在”屏幕底边。

5. 效果展望

通过这一套架构，看板娘从一个“静态贴纸”进化成了能感知环境、能理解内容、能智能对话的虚拟助理。未来可以进一步接入 RAG（检索增强生成），让看板娘能够根据博客的全部历史文章内容进行深度问答。
